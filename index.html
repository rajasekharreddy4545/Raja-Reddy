Agentic AI & Featured Projects

Real-world autonomous agents, intelligent retrieval pipelines, and enterprise-grade platforms.

Quality Control (QC) Agent

Architected an autonomous Quality Control (QC) Agent that directly incorporates automated pre-login checklist audits and operational inspections. Built with Python and integrated with LLMs, this agent seamlessly collaborates with an integrated Document Intelligence Agent to extract, parse, and evaluate unstructured document submissions, ticket workflows, and login access checklists against enterprise SOP benchmarks. Exclusively utilizes MongoDB for schema-flexible persistence of audit reports and verification logs, with total host and application-level observability configured via Prometheus, Grafana, Node Exporter, and cAdvisor to monitor system metrics, inspection latency, error rates, and audit throughput in real time.

Python LLM MongoDB Document Intelligence Agent Prometheus Grafana Node Exporter cAdvisor Agentic AI

KYC Verification Agent

Engineered an autonomous KYC Verification Agent utilizing Python, LLMs, and custom Tools Integration (agentic tool calling) to automate customer onboarding and fraud detection. Deeply integrated with Document Intelligence to extract and cross-examine identity documents and validation parameters, containerized via Docker and stored in MongoDB. Personally architected and implemented total host and container observability using Prometheus, Grafana, Node Exporter, and cAdvisor for system resource monitoring, container performance, latency tracking, pass/fail ratios, and automated alerting, secured via Kong API Gateway.

Python LLM Tools Integration Document Intelligence MongoDB Docker Prometheus Grafana Node Exporter cAdvisor
